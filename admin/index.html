Conectar ao GitHub

O painel precisa de uma chave de acesso do GitHub para salvar as alterações no site.

Se você já tem a chave em outro aparelho, não precisa criar outra. No aparelho que ainda entra no painel, abra Publicação → Acesso técnico para publicar, toque em Gerenciar chave, depois em Copiar, mande o código para você mesmo (WhatsApp, e-mail) e cole aqui embaixo. A mesma chave funciona no celular e no computador ao mesmo tempo.
Não tenho a chave em aparelho nenhum — criar uma nova no GitHub

O painel usa DOIS repositórios, e a chave precisa alcançar os dois: materialsengercorretores (o site) e senger-financeiro (o cofre privado dos custos). Uma chave só com o primeiro salva no site mas nunca guarda os custos, e eles somem ao trocar de aparelho.

  1. Entre no GitHub com a conta sanchaikraemer.
  2. Abra esta página do GitHub. Se aparecer uma tela de erro com um unicórnio rosa, é o GitHub que demorou demais: atualize a página que ela abre.
  3. Em Token name, escreva um nome que ainda não exista — por exemplo Painel Senger. Se o GitHub disser que o nome já está em uso, mude o nome; não use Regenerate na chave antiga, porque isso desliga o outro aparelho.
  4. Em Expiration, escolha 90 dias (ou 1 ano). Chave sem vencimento vale para sempre mesmo se o celular for perdido ou o código vazar — e quem publica com ela é a sua conta. O painel avisa quando estiver perto de vencer, e trocar leva um minuto.
  5. Em Repository access, marque Only select repositories e escolha os dois: materialsengercorretores e senger-financeiro.
    Se o senger-financeiro ainda não existir, crie-o antes em github.com/new, marcando Private. É onde os custos ficam — nunca no repositório do site, que é público.
  6. Em Permissions → Repository permissions, deixe Contents: Read and write. Só isso. Não marque Administration, Actions, Workflows nem nada em Account permissions: o painel não usa e, se a chave vazar, é menos estrago.
  7. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.

A chave fica guardada só neste aparelho (no navegador). Ela não vai para o site, não entra no data.js e não aparece em endereço nenhum. Se este aparelho for perdido ou emprestado, apague a chave em Publicação → Acesso técnico e gere outra no GitHub.

    Como as contas são feitas

    Margem = o preço menos o custo. Enquanto a venda desejada estiver vazia, a margem mostrada é a do preço que está no site; assim que você informa a venda desejada, ela passa a mostrar a margem dessa venda. Tocando no ⌄ ao lado do nome do item aparecem: Custo - 5% = custo × 0,95 e Custo - 10% = custo × 0,90, para quando o cliente pede abatimento. Custo e margem são informação interna e não vão para o site.

    Acesso técnico para publicar

    A chave do GitHub só é necessária para o painel conseguir gravar as alterações. Não precisa mexer nela no uso normal.

    O que protege de verdade é a chave, não a senha. Este painel é uma página que roda no navegador, sem servidor — a senha de entrada só esconde a tela de quem abrir o endereço por acaso; quem entende de navegador passa por ela. Quem não tem a chave do GitHub, porém, não publica nada e não abre o cofre dos custos. Por isso: guarde a chave como guardaria a senha do banco, use uma chave com validade, e apague a chave do aparelho que sair da sua mão.
