MATERIAL SENGER CORRETORES

O que é
-------
Portfólio comercial dos empreendimentos da Construtora Senger, com um painel
administrativo que o dono usa pelo celular.

NÃO é um site público de captação. São duas coisas:
  1. uma ferramenta de trabalho do corretor (buscar, conferir, selecionar e
     enviar imóveis);
  2. uma apresentação privada e dirigida, enviada pelo WhatsApp a um cliente que
     JÁ demonstrou interesse — ele recebe exatamente o que o corretor escolheu
     mandar, e não um catálogo aberto para navegar.

Qual é a versão
---------------
NÃO EXISTE UM NÚMERO DE VERSÃO NESTE ARQUIVO, de propósito: ele envelhecia
sozinho e passava a mentir. A versão que está no ar é sempre a que está em:

  - index.html          — os ?v= dos arquivos
  - sw.js               — o CACHE e os ?v= do CORE
  - admin/index.html    — o VERSAO_PAINEL (a versão do painel)

O painel mostra o próprio número no alto da tela e avisa, com uma faixa amarela,
quando a página aberta for mais velha que a que está publicada.

Onde fica cada coisa
--------------------
  index.html + app.js + styles.css   o site
  data.js                            TODOS os dados: META (mês da tabela, INCC)
                                     e EMPREENDIMENTOS
  admin/index.html                   o painel, uma página só, sem build
  sw.js                              service worker (PWA)
  assets/                            fotos, plantas, logos, folder
  l/                                 páginas-ponte (a prévia do WhatsApp)
  tools/                             os scripts (abaixo)

Antes de publicar qualquer mudança
----------------------------------
  node tools/validar.js
      Confere o cadastro inteiro: sintaxe dos JS, IDs repetidos, unidades
      duplicadas, status inválido, preço incoerente com o status, arquivo de
      foto que não existe, planta apontando para o nada, RI faltando, ponte
      faltando ou sobrando, segredo dentro de arquivo público e a versão batendo
      entre index.html e sw.js. Também acusa REGRESSÃO DE MATERIAL — folder,
      vídeo, capa, logo, galeria ou planta que existia e sumiu.
      Sai com erro (código 1) quando há algo quebrado.

  node tools/testar-navegador.js
      Abre o Chromium e exercita de verdade: o site do corretor, o modo cliente
      (link de empreendimento, de unidade e de seleção), o painel administrativo
      (com a API do GitHub simulada, sem token de verdade) e o service worker.

  node tools/gerar-pontes.js
      Só é obrigatório depois de ACRESCENTAR ou REMOVER unidade no data.js.
      Mudar status não precisa: a ponte é gerada para toda unidade do cadastro,
      inclusive a vendida, justamente para o painel poder desfazer uma venda sem
      quebrar o link que já foi enviado ao cliente.

  node tools/validar.js --gravar-retrato
      Atualiza tools/materiais.json, que é a referência da guarda de regressão
      de materiais. Rode DEPOIS de acrescentar material de propósito.

Como publicar
-------------
O normal é o dono publicar pelo próprio painel: ele grava direto na branch main,
sobe o número da versão sozinho e manda data.js, index.html e sw.js no MESMO
commit — ou entra tudo, ou nada entra.

Mudança feita direto no repositório (fora do painel) precisa subir o número à
mão nos três lugares listados acima, antes do merge.

Custos e margens
----------------
NUNCA vão para este repositório, que é público. Eles ficam no navegador do
aparelho e num repositório PRIVADO da mesma conta (senger-financeiro), alcançado
com a mesma chave do GitHub que o painel já usa.

A chave do GitHub precisa alcançar OS DOIS repositórios —
materialsengercorretores (o site) e senger-financeiro (o cofre) — com permissão
Contents: Read and write, e nada além disso.

Padrão dos arquivos de material
-------------------------------
  Capa principal    WEBP, JPG ou PNG — 1600 × 900 px — até 5 MB
  Fotos da galeria  WEBP, JPG ou PNG — 1600 × 900 px — até 5 MB cada
  Plantas           WEBP, JPG ou PNG — 2000 × 2000 px — fundo claro — até 6 MB
  Logo              PNG ou WEBP — 1600 × 600 px — fundo transparente — até 3 MB
  Folder            PDF — até 25 MB
  Vídeo             MP4, WebM ou Ogg — 1920 × 1080 px — até 80 MB; acima disso,
                    usar YouTube ou Vimeo

Arquivo anexado pelo painel vai para o próprio repositório, em
assets/<empreendimento>/...
